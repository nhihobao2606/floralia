# Floralia Herbal Tea

**Floralia Herbal Tea** là website thương mại điện tử giới thiệu và kinh doanh các sản phẩm trà thảo mộc. Dự án hướng đến việc mang lại trải nghiệm mua sắm trực tuyến thuận tiện, giúp khách hàng dễ dàng khám phá và lựa chọn những sản phẩm phù hợp.
